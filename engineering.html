Engineering Report

Costruito per il lavoro reale.Testato oltre l'uso normale.

SlangBit non è soltanto uno strumento di traduzione offline. È una utility di produttività per Windows progettata per portare la traduzione AI locale direttamente nelle applicazioni che le persone usano già.

Questa pagina riassume la validazione tecnica alla base di SlangBit: workflow reali, architettura offline, stress test, indagine sulla certificazione Microsoft Store e hardening dell'input.

Workflow

Tradurre senza uscire dal proprio lavoro.

SlangBit è stato progettato per ridurre il numero di interruzioni normalmente richieste dai workflow di traduzione.

CONTINUA A LAVORARE

Esempio di workflow reale

Un testo può essere scritto in OpenOffice, copiato negli appunti e tradotto direttamente nel campo descrizione di un browser semplicemente posizionando il cursore nel campo di destinazione e premendo ALT + Z.

SlangBit legge gli appunti, traduce localmente, aggiorna gli appunti e inserisce il testo tradotto nell'applicazione attiva.

Architettura

Offline-first per progettazione.

SlangBit esegue la traduzione localmente usando modelli linguistici AI installati e un server di traduzione locale integrato.

Applicazione Windows

Applicazione desktop Flutter con hotkey globale, integrazione nella tray, workflow tramite appunti e Package Manager.

Server locale

Server locale integrato basato su Python che gestisce rilevamento dei modelli linguistici, richieste di traduzione e normalizzazione dell'input.

Modelli AI locali

I modelli CTranslate2 e i tokenizer Marian vengono eseguiti direttamente sul computer dell'utente dopo l'installazione dei pacchetti lingua.

Appunti → SlangBit Desktop → Server locale → CTranslate2 → Modello AI locale → Appunti → Applicazione attiva

Indagine sulla certificazione

Un problema difficile di certificazione è diventato hardening del prodotto.

Durante la certificazione Microsoft Store è stato investigato sistematicamente un errore di traduzione collegato all'input.

Segnalazione iniziale

Un report di certificazione mostrava un errore di traduzione su una descrizione lunga contenente tag HTML letterali di interruzione di riga.

Test delle ipotesi

Sono stati testati ambiente Windows, tempi di avvio, warmup del server, testo della descrizione Store, README, HTML, Markdown, formati degli appunti e macchine virtuali.

Riproduzione

Il problema è stato riprodotto soltanto quando testi lunghi contenevano elementi letterali <br> ripetuti invece di normali interruzioni di riga.

Causa principale

La pipeline di traduzione riceveva le interruzioni di riga come testo HTML letterale, creando una rappresentazione di input insolita e non prodotta dai normali workflow di copia.

Correzione

Il server locale è stato aggiornato per normalizzare le interruzioni di riga HTML letterali in normali interruzioni di riga prima della traduzione.

Risultato

L'input che in precedenza falliva è stato tradotto correttamente e la build aggiornata ha completato la certificazione Microsoft Store.
